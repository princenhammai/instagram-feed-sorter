# Instagram Feed Sorter v0.3.2

The full Instagram Reel/Post Sorter: seven rankings, count/date ranges, player, filters, exports, downloads, local saved-post folders and optional transcription.

## Install

Download **instagram-feed-sorter-v0.3.2.zip**, extract it, then use Developer mode → Load unpacked in desktop Chrome. Select the folder containing `manifest.json`. Sign in to Instagram yourself and open a profile's Reels tab.

No Node.js, API key or server is needed for basic sorting. Optional transcription uses your own provider/key. This is a desktop Chromium build; mobile Chrome, the Instagram app, Safari and Firefox are not supported.

## Included

- Restored complete Sorter popup and saved-post library.
- Portable production ZIP with installation guides, privacy information and license notices.
- Compatibility fallback for offscreen documents on older Chrome versions.
- Standard CDN host permission patterns.
- Source, tests and repeatable packaging/build workflows.

For updates, replace files in the same loaded folder, reload the extension, then refresh Instagram. Existing local libraries do not automatically sync to other devices.
